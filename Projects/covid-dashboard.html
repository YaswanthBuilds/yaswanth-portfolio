COVID-19 Analysis Dashboard

A data analysis and visualization project using Excel and Power BI to organize pandemic-related data and communicate trends through visual summaries.

ExcelPower BIData cleaningVisualization
← Back to selected projects
01 / Problem

The challenge

Public-health datasets can contain many measures and time periods. A dashboard can help make the important patterns easier to explore, provided that the data, dates, definitions, and caveats are clear.

02 / Approach

How I approached it

  • Prepare and organize the source data in Excel.
  • Use Power BI to shape the information into visual summaries and comparisons.
  • Choose charts and labels that make trends easier to read.
  • Validate the source, measures, and date range before drawing conclusions from the dashboard.
03 / Technology

Tools & methods

Microsoft Excel · Microsoft Power BI

04 / Reflection

What this project explores

This project builds practice in data preparation, visual communication, and turning a dataset into a dashboard that is easier to interpret.

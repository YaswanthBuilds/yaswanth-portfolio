# Yaswanth Vadranam — Coming Soon Portfolio

A static portfolio landing page built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation interaction
- `assets/yaswanth-portrait.png` — supplied portrait image

## Preview locally
Open this folder in VS Code, then open `index.html` in a browser. For a more convenient local workflow, install the Live Server extension in VS Code and choose **Open with Live Server**.

## Before publishing
1. Replace the `href="#"` values for GitHub and LinkedIn with your real profile URLs.
2. Add your email address to the `mailto:` link.
3. Decide what the two arrow-only buttons should do before making them functional.
4. Review the portrait crop on desktop and mobile.

## Deploy to Vercel
This is a static site. Push the project folder to a GitHub repository, import that repository into Vercel, and deploy. No build command or framework preset is required.
